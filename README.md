# Coldbrew Calculator

This is a *highly* personal, opinionated cold brew calculator based on my specific use case.

1. I use imperial vessels for my cold brew
2. I use grams (or mg) for measuring everything else
3. I like to adjust tap water to near the Hendon study water hardening compound ratios
4. I really don't like wasting water or beans

That's it! I don't expect you to use it!
